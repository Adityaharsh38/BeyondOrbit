# 🚀 BeyondOrbit

## 📌 Project Overview

**BeyondOrbit** is a modern and interactive web application that allows users to explore and analyze real-time space mission data. The platform provides detailed insights into various space launches, including mission names, launch dates, rocket details, and mission status.

Designed with a futuristic and visually engaging interface, BeyondOrbit transforms raw space data into an intuitive dashboard experience.

---

## 🎯 Purpose of the Project

The objective of this project is to:

* Demonstrate the use of JavaScript for building dynamic web applications
* Integrate and display real-time data from a public API
* Implement interactive features such as search, filtering, and sorting
* Create a responsive and visually appealing user interface

---

## 🔌 API Used

This project uses the **SpaceX API** to fetch real-time data about space missions and launches.

* API Endpoint: https://api.spacexdata.com/v4/launches
* Data includes:

  * Mission name
  * Launch date
  * Rocket details
  * Launch success/failure status

(Optional Enhancement)

* NASA API: https://api.nasa.gov/ (for space-related images and additional data)

---

## ✨ Features

### 🔍 Search Functionality

Users can search for space missions by name using a dynamic search bar.

### 🎯 Filtering

Users can filter missions based on:

* Launch success (Successful / Failed)
* Mission type (Upcoming / Past)

### 📊 Sorting

Users can sort missions based on:

* Launch date (ascending/descending)
* Mission name (alphabetical order)

### ⭐ Favorites System

Users can mark missions as favorites and store them using local storage.

### 🌙 Dark Mode

A toggle feature that allows users to switch between light and dark themes.

### 🖱️ Interactive UI

* Buttons like "View Details" and "Favorite"
* Smooth hover effects and animations
